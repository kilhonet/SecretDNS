## 概要

Web サイトを開くとき、コンピューターは 2 つの情報を平文で送ります。サイトの IP アドレスを問い合わせる **DNS クエリ**と、HTTPS 接続の最初のパケットに含まれる**サイト名(SNI)**です。通信事業者やネットワーク管理者の検閲装置(DPI)はこの 2 つを読み取ってどのサイトにアクセスしているかを把握し、必要に応じて接続を切断したり警告ページへ誘導したりします。

SecretDNS は**鍵ボタン**を 1 回押すだけでこの 2 つの穴をふさぎます。

- **DNS** — コンピューターの DNS クエリを Cloudflare などのサーバーで**暗号化(DoH)**して処理します。Windows のネットワーク設定には一切触れないため、プログラムを停止すればその場で元に戻り、実行中にコンピューターが突然落ちても、再起動すれば何の痕跡もなくいつも通りインターネットが使えます。
- **SNI** — HTTPS 接続時に**サイト名が検閲装置に見えないように**処理します。サイトへの接続自体は普段どおりで、名前の部分だけを処理するため速度低下はほとんどありません。

銀行や決済など断片化すると動作しなくなるサイトは内蔵の**例外リスト**でそのまま通し、**レポート**でどのサイトがどう処理されたかを確認できます。インターネットの自由が保障されていない国でよく見られる **451 エラー**(サイト側がその国からの接続自体を拒否するもの)のように DNS の回避では開けないサイトは、**混合プロキシ**でそのサイトだけ他国経由で接続できます。指定したドメイン以外は経由しないため、それ以外のインターネット速度はそのままです。

SecretDNS は VPN ではありません。IP アドレスを隠したり通信全体を暗号化したりはせず、検閲に使われる DNS と SNI の 2 か所だけを処理します。

## 主な機能

- **ワンクリック** — ホーム画面の**鍵ボタン**を押すだけ。トレイアイコンのクリックや、**設定**右上の鍵でもオン/オフできます。
- **DNS over HTTPS** — 既定は Cloudflare。サーバーを自分で追加し複数にチェックを入れておくと自動で切り替えて使います。暗号化なしで**指定サーバー**(例: 1.1.1.1)だけを使うモードもあります。
- **Windows 設定を変更しない** — ネットワークアダプターの DNS 設定は変更しません。停止すれば痕跡は残らず、実行中に停電や強制終了があっても再起動すれば普段どおりに戻ります。
- **SNI 断片化** — HTTPS・HTTP 接続でサイト名が漏れないようにします。
- **例外リスト / 手動リスト** — 断片化しないサイト、または断片化するサイトだけを指定します。銀行・決済・ポータル・ゲームなど約 160 ドメインが既定の例外として組み込まれています。
- **ブラウザのみ** — 主要ブラウザの通信にだけ断片化を適用し、ゲームや業務ソフトには触れません。最初からオンになっています。
- **偽装パケット** — 断片化だけでは足りない回線向けの追加の回避方式です。
- **切れない接続** — 開始前に DNS サーバーへ届くかを確認し、実行中にサーバーが応答しなくてもインターネットは切れず、サーバーが戻れば自動的に再開します。スリープ復帰や Wi-Fi 切替後もインターネットが止まりません。
- **レポート** — DNS・SNI 別にドメインと適用結果(暗号化、断片化、平文、サーバー経由 …)を別ウィンドウの表で表示し、コピーできます。
- **混合プロキシ** — リストに書いたドメインだけ海外サーバー経由で接続します。DNS では回避できない 451 ブロックのサイトを開くときに使い、それ以外は普段どおり直接接続するため速度の損失はありません。
- **自動起動・トレイ** — Windows 起動時に自動実行、ウィンドウを閉じると通知領域へ最小化。
- **22 言語** — Windows の表示言語に従い、**設定**の**言語**で自分で選ぶこともできます。

## 使い方

### はじめての使い方

1. SecretDNS を起動します。管理者権限の確認画面が出たら **[はい]** を押します。
2. ホーム画面中央の**鍵ボタン**を押します。鍵が金色に光れば実行中で、通知領域(トレイ)のアイコンも金色に変わります。
3. 普段どおりブラウザを使います。ほかにすることはありません。
4. オフにするには鍵をもう一度押すか、トレイアイコンを 1 回クリックします。ウィンドウを閉じても(×)終了せず、トレイに入ります。

何をオン/オフにするかは、右上の**歯車**ボタンで開く**設定**で決めます。実行中は設定がロックされるので、変更するには先に停止してください(**言語**と **[ログ表示]** は実行中でも使えます)。**設定**右上の鍵ですぐに実行・停止できるので、ホーム画面に戻る必要はありません。

### 画面構成

**ホーム画面** — 中央に**鍵ボタン**(実行/停止)、右上に**歯車**(設定)、下のステータスバーにバージョンがあります。上部のロゴを押すとホームページが開きます(ほかの画面のロゴも同じです)。

**設定** — 左上の矢印でホーム画面に戻り、右上の鍵で実行/停止します。鍵は停止中は開いた灰色、実行中は閉じた金色です。

| 項目 | 内容 |
|---|---|
| **DNS設定** — 無効 / 指定サーバー / DNS over HTTPS | DNS クエリの処理方法。指定サーバー・DNS over HTTPS の行の **[サーバー設定]** でそれぞれのサーバーリストを編集します |
| **SNI設定** — 無効 / 断片化 / 断片化ⓜ | 断片化をすべてのサイトに適用(例外リストを除く)するか、手動リストのサイトにだけ適用するか |
| **例外** / **手動** リスト | 断片化を選ぶとその行の下に例外リスト、断片化ⓜを選ぶとその行の下に手動リストの入力欄が表示されます。1 行に 1 つ書きます |
| **混合プロキシを有効化** | リストのドメインだけ海外サーバー経由。オンにするとすぐ下にリストの入力欄が表示されます(DNS 設定がオンである必要あり) |
| **ブラウザのみ** | ブラウザの通信にだけ断片化・偽装パケットを適用 |
| **偽装パケットを有効化** | 断片化だけでは足りない回線向けの追加の回避方式 |
| **レポートを有効化** + **[ログ表示]** | レポートを記録します。**[ログ表示]** でレポートウィンドウを開きます |
| **起動時に実行** | ログオン時にトレイで自動開始。前回実行中だった場合は保護も自動でオンにします |
| **言語** | 表示言語。**システム**なら Windows の表示言語に従います |

**DNSサーバー設定** — **[サーバー設定]** を押した側(指定サーバーまたは DNS over HTTPS)のリストが表で表示され、下に **[追加]**・**[編集]**・**[削除]** があります。

**レポートウィンドウ** — **種別**(DNS・SNI・VPN)・**ドメイン**・**適用**の 3 列です。同じ行は 1 回だけ残り、適用欄が空の行(何も適用せず送出したもの)は薄く表示されます。**[コピー]**・**[コピー(全体)]** はタブ区切りテキストでコピーし、**[クリア]** はリストを消去します。ウィンドウのサイズは変更でき、メインウィンドウをトレイに隠してから再び開くと、レポートウィンドウも一緒に戻ります。

**トレイアイコン** — 停止中は灰色、実行中は金色です。1 回クリックで実行/停止が切り替わります。右クリックメニューには **SecretDNS**(ウィンドウ表示)・**実行**・**停止**・**Kilho.net**・**終了**があります。アイコンにマウスを載せるとバージョンと現在の状態が表示されます。

### こんなときは

**特定のサイトが警告ページに飛ばされる、または接続が切れる**
既定の設定(DNS **指定サーバー**または **DNS over HTTPS** + SNI **断片化**)で鍵を押すだけでほとんど解決します。レポートを有効にしてそのサイトを開くと、`SNI` 行に**断片化**、`DNS` 行に**平文**または **DNS over HTTPS** と付いていれば正常です。それでもだめなら下の**偽装パケットを有効化**を試してください。

**SecretDNS をオンにした後、あるサイトが開かなくなった(銀行・決済・ゲームのログインなど)**
そのサイトの通信が断片化に弱い場合です。**設定**で**断片化**の行の下にある**例外**リストにドメインを 1 行追加して、もう一度実行してください。
- `.example.com` のように**ドットで始めて**書くと `example.com` とすべてのサブドメイン(`www.example.com`、`m.example.com`)に一致します。
- アドレスバーの URL をそのまま貼り付けても構いません — `https://`、`www.`、後ろのパスは自動的に取り除かれます。
- 入力欄から別の場所をクリックするか、**設定**を離れるか、実行すると保存され、**次回の実行から**適用されます。**設定**右上の鍵ですぐ実行すれば、ホーム画面に戻る必要はありません。
- 銀行・カード・決済・ポータル・ショッピング・ゲーム・政府(`.go.kr`)・学校(`.ac.kr`)など約 160 ドメインはすでに例外として組み込まれているので、書く必要はありません。リストを空にしても組み込みの例外はそのまま働きます。

**いくつかのサイトだけ断片化して、ほかには触れたくない**
SNI 設定を**断片化ⓜ**に変えると、その行の下に**手動**リストの入力欄が表示されます。ここに書いたドメインだけを断片化し、それ以外はすべてそのまま送ります。問題のサイトが 1〜2 個だけなら、こちらの方が安全です。書き方のルールは例外リストと同じで、リストが空の場合は実行前にドメインを入力するよう案内されます。

**DNS だけ暗号化して断片化は使わない**
DNS 設定を **DNS over HTTPS**、SNI 設定を**無効**にします。逆に DNS はそのままで断片化だけ使うなら DNS を**無効**にしてください。両方無効だと「実行する機能がありません。」と表示されます。

**「暗号化(DoH) DNS サーバーに接続できません。」と表示される**
会社や学校の回線には、インターネットは使えるのに一部の DoH サーバーには接続できないところがあります。方法は 2 つです。
- DNS over HTTPS の行の **[サーバー設定]** を押し、リストで別のサーバー(例: 既定リストの **cloudflare-dns.com**)にチェックを入れます。
- または DNS 設定を**指定サーバー**に変えます。暗号化はされませんが、Windows 設定を変えずに別の DNS サーバーを使う効果はそのままです。

**別の DNS サーバーを使いたい**
DNS 設定の**指定サーバー**または **DNS over HTTPS** の行にある **[サーバー設定]** を押すと、そのサーバーリストが開きます。
- **[追加]** で**名前・アドレス1・アドレス2**(予備、空でも可)を入力します。指定サーバーは `8.8.8.8` のような IPv4 アドレス、DoH は `https://1.1.1.1/dns-query` や `https://dns.google/dns-query` のようなアドレスです。
- 項目の前の**チェック**を入れたサーバーだけを使います。複数にチェックを入れると、1 つが応答しないとき別のサーバーへ自動的に切り替わります。1 つもチェックしていない場合は Cloudflare を使います。
- 既定リストには Cloudflare(チェック済み)と Google(チェックなし)が入っています。
- 変更したリストは**次回の実行から**適用されます。

**ゲームや業務ソフトに影響を与えたくない**
**ブラウザのみ**をオンにしておいてください(最初からオンになっています)。断片化と偽装パケットを Chrome・Edge・Firefox・Whale などの主要ブラウザの通信にだけ適用し、ほかのプログラムには触れません。DNS の処理はプログラムに関係なく適用され続けます。
逆にブラウザ以外のプログラム(ダウンロードソフトなど)にも断片化が必要なら、**ブラウザのみ**をオフにします。

**断片化してもまだブロックされる回線**
**偽装パケットを有効化**を試してください。断片化だけでは通り抜けられない検閲装置向けの追加の回避方式で、実際の接続には影響しません。

**ブロックされたサイトだけ海外サーバー経由で接続したい(混合プロキシ)**
インターネットの自由が保障されていない国では、サイト側がその国からの接続自体を拒否し、ブラウザに **451 エラー**(Unavailable For Legal Reasons)が表示されることがあります。自由なインターネットのある国ではほとんど見られないケースです。この場合は DNS の暗号化や断片化では開けません — 接続元の国を見てブロックしているためです。混合プロキシはそうしたサイトだけを他国のサーバー経由で接続させます。
DNS 設定をオンにした状態で**混合プロキシを有効化**にチェックを入れると、すぐ下にリストの入力欄が表示されます。1 行に 1 ドメイン(`.example.com`、例外リストと同じルール)を書いて実行します。
- リストのドメインだけ海外サーバーを経由し、それ以外は普段どおり直接接続します。VPN の全体接続と違い、ほかのサイトの速度はそのままです。
- サーバーは実行のたびに自動で割り当てられ、応答がなければ次のサーバーへ自動的に切り替わります。
- レポートには種別 **VPN**、適用**サーバー経由**として残ります。
- 混合プロキシは DNS 設定がオンである必要があり、DNS を無効にすると一緒にオフになります。

**コンピューターを起動するたびに自動でオンにしておきたい**
**起動時に実行**にチェックを入れます(インストーラー版はインストール時にすでに登録されています)。ログオンするとウィンドウなしでトレイから開始し、**前回実行中の状態にしていた場合**は保護も自動でオンにします。自分で停止して終了した場合は、次回起動時はオンにせず待機します。
起動直後に Wi-Fi の接続が遅れても、ネットワークがつながれば自動で開始します。

**ウィンドウを閉じてもオンのままにしておきたい**
閉じる(×)を押しても終了せずトレイに入るので、特に何もする必要はありません。完全に終了するにはトレイアイコンを右クリック → **終了**(確認画面が出ます)。終了すると保護も一緒にオフになります。

**表示言語を変えたい**
**設定**の一番下の**言語**で選ぶと、すぐにその言語に切り替わります。実行中でも変更できます。**システム**を選ぶと、再び Windows の表示言語に従います。

**今どのサイトがどう処理されているか見たい**
**レポートを有効化**をオンにして **[ログ表示]** でレポートウィンドウを開きます。実行中にアクセスしたドメインが 1 行ずつたまります。**[ログ表示]** は実行中でも押せます。

| 種別 | 適用 | 意味 |
|---|---|---|
| DNS | **DNS over HTTPS** | 暗号化サーバーで問い合わせました |
| DNS | **平文** | 指定サーバーで問い合わせました(暗号化なし) |
| SNI | **断片化** | サイト名を断片化して送りました |
| SNI | (空欄) | 例外リストのサイトなのでそのまま送りました |
| VPN | **サーバー経由** | 混合プロキシで海外サーバーを経由しました |

**[コピー(全体)]** でコピーしてメモ帳や Excel に貼り付けると列がそのまま分かれます。

**DNS サーバーが応答しなくてもインターネットが切れない理由**
SecretDNS は実行前に DNS サーバーへ届くかを先に確認し、実行中にサーバーがしばらく応答しなくてもインターネットが止まらないよう自動で処理します。サーバーが戻れば自動的に元の動作に戻り、その間の状態はトレイアイコンとレポートで確認できます。スリープから復帰したり Wi-Fi を切り替えたりしても、改めて実行し直す必要はありません。

**ドライバーの案内画面が表示される**
まれに、コンピューターを再起動してから実行するよう求める案内が出ることがあります。案内どおり再起動すれば大丈夫です。

**実行中にコンピューターが落ちた**
心配ありません。SecretDNS は Windows のネットワーク設定を変えず実行中だけ動作するので、停電や強制終了の後にもう一度起動すればインターネットは普段どおりです。起動時に実行をオンにしていれば、ログオン後に自動で再開します。

## 設定

**設定**で変更し、変更するとすぐ保存されます。ほとんどは**次回の実行から**適用され、アップデートしても設定は維持されます。

| 項目 | 既定値(インストーラー版) | 既定値(ポータブル版) |
|---|---|---|
| DNS設定 | 指定サーバー | 指定サーバー |
| SNI設定 | 断片化 | 断片化 |
| DNS サーバーリスト | 指定サーバー: Cloudflare ✓, Google / DNS over HTTPS: Cloudflare ✓, cloudflare-dns.com ✓, Google | 同じ |
| 混合プロキシを有効化 | オフ | オフ |
| ブラウザのみ | オン | オン |
| 偽装パケットを有効化 | オフ | オフ |
| レポートを有効化 | オフ | オフ |
| 起動時に実行 | オン | オフ |
| 言語 | システム | システム |

表示言語は Windows の表示言語に従い(22 言語、それ以外は英語)、**設定**の**言語**で変更できます。

## 動作環境

- Windows 10 または Windows 11(32 ビット・64 ビットの両方)
- **管理者権限** — 起動のたびに権限の確認画面が表示されます。
- 追加のランタイムは不要です。
- インターネット接続 — DNS サーバーの確認と新バージョンの案内に使います。

## アップデート

SecretDNS は自動的にはアップデート**しません**。起動時に新バージョンの有無を確認して案内画面を表示し、**[はい]** を押すとダウンロードページが開いてプログラムが終了します。新バージョンは内部検証の後に手動で配布され、[SecretDNS ページ](https://kilho.net/secretdns)で告知されます。[アップデートポリシー](https://en.kilho.net/archives/notice/2940)をご覧ください。

## ライセンス

SecretDNS は**フリーウェア**です。会社、自宅、官公庁、学校など、どこでも制限なく無料で使え、自由に再配布できます。
